The amorphous profile

What is an amorphous profile?

Amorphous profile

noun · pattern profileDEF. 01

The pattern profile at the center of the system. We refer to the pattern as the amorphous profile because it continually evolves.

At the center of the system are the pattern profiles. Patterns are derived from baselines in the system, which are used to compare and match against new data. Based on the match percentage, the system determines which course of action to take.

These patterns can reside at various levels within the organization, including corporate, user, and workflow levels. In user patterns, patterns are continually informed by historical behavior, data from other patterns with attributes (people like me), or even, sometimes, a base set of rules (roles & permissions), and real-time interaction with the system (e.g., location, time).

Generating a profile consists of 6 core parts.

These attributes are important because they create the base of what we call the Digital Twin.

The essence of a participant’s traits, behaviors, and patterns is distilled into an AI-driven virtual twin that participates in a continuous AI-driven simulation experience.

The profile and attributes of a real-world participant are mapped to key attributes within the virtual persona during user configuration.

You may wonder, how will this transform our customer experience?

The answer lies in building a personal IT assistant powered by connected AI, delivered through continuous interaction & engagement.

Digital twin – the AI integration

Here are the core elements that made this integration possible:

Core element

Connected Engagement

Merging the power of generative content, digital twin, digital human, hyper-personalization, and workflow automation into a single connected experience.

Core element

Personalized Digital Advisor

The system's interaction can mold the user's personality, and the system's background should progress to improve the overall experience. The Avatar's functionality acknowledges and recalls the user’s preferences across all devices to ensure effortless transitions.

Every user interaction within the system informs the profile, determining and surfacing user-specific functionality. To start, a broad set of functionality surfaced as the user began using the system (such as rules). As the user interacts with the system, the functionality becomes more focused on the features with the most interaction. Also, the system will utilize informational and clarification responses. The interface must align with the user’s behavior to provide the user with further insights. This also removes the need for complex navigation structures.

Core element · Simplified UX

Three panel design

Core element

Virtual Explainer

The digital advisor operates similarly to a tour guide, focusing on key information and allowing users to ask targeted questions about the highlighted content. Its purpose is to quickly filter and provide essential contextual information to aid in decision-making.

For sales agents, the AI assistant even gives additional help. If a user requests further assistance or a subject is better handled by a human, the AI can identify which sales agent is responsible for that user and trigger a notification so the human agent can get in touch with the user when help is needed.

Core element

Evolving experience

The assistant can learn how you prefer to interact and the level of customization you prefer.

Feature highlights

Here's a list of features that we think make this experience amazing:

Feature

Customized recommendation

The system will gather information about you, your company, and your navigation, and provide you with informed recommendations.

As you navigate and request specific products or services, the assistant will cross-reference the information it has about you and find the best match between your profile and what you’re looking for.

In order to convey that information in a good way to the user, metrics will be displayed - and note that those metrics will be chosen depending on the context of the request, so for example, if the user is requesting a laptop to run SolidWorks (which requires a lot of GPU power), it will give you metrics about rendering and stability.

Feature

Collaborative workspace

Where users, sales agents, and AI agents can work together to build the best solution live.

Collaborative workspace

6 areas
1 · Product exploded view
Expanded view with details about the product being discussed
2 · Interactive space
All users can interact inside this space and see the same information
3 · Configuration panel
Where users can select pieces of hardware and software to configure the product
4 · AI agent panel
The AI assistant is always handy and can be found in the right panel
5 · Video meeting
Meet with sales agents and discuss live with video meetings
6 · Chat
The chat feature is retroactive and will be fed from both chat input and video meeting transcripts
Feature

User thermometer

Monitor users' activities and notify in case there is a need for human intervention.

Feature

Digital Advisor Log

Internal AI assistant for sellers. Accelerate processes and help close more deals.

Digital Advisor Log

3 steps
1 · Request processing
Whenever the AI assistant identifies a request being made by any user, it processes the known information and generates a recommendation for the sales agent to use in the collaborative workspace
2 · Product recommendation
Once the recommendation is ready, it will pop up on the log, and the sales agent can use it or see it on another screen to validate if the recommendation is good enough
3 · Action line summary
As recommendations and actions are done, they get stored in the action line summary, so whenever the sales agent wants or needs to use them, they can just click on the right icon and use them in the collaborative workspace. This whole process removes a lot of friction from the quoting and purchasing processes, since the AI agent will do most of the time-consuming work, while users and sales agents can discuss the configuration of the products
