Case file 01 · Concept figures · prototype

Figures that show the idea, not just name it.

The current concept images are icon diagrams: circles, symbols and arrows that label an idea. Your research is about structure, variation and rules, so each figure should demonstrate its point. These four use the same building blocks as the rest of the site: wireframe blocks, your tag colors and the original study's template legend.

  • Show, don't label
  • One idea per figure
  • Plays once, then the reader drives
  • Same visual language as the method

Fig. 02 · Entry 02 · Introduction

A web page is two layers

The axiom, made literal: a page is a content layer (graphic components) with a culture layer (who it's for) on top. Assembled, they look like one page. Exploded, you see the two pillars.

Replaces
Why it works

The icon version asks readers to decode symbols. The layered version shows that culture sits on the same page as the components, so the axiom reads at a glance.

It plays when scrolled into view: assembled → exploded. The button lets readers compare.

Fig. 03 · Entry 02 · Introduction

From people to pages

Your text says that you start by understanding people, then you define the system, and only then do pages and flows exist. The figure plays that order as an assembly line: each stage hands its output to the next, and the page is built from the components of stage 2.

Replaces
Why it works

The arrows in the current image read as a list. Here each stage visibly produces something the next one uses: the stage 3 page is assembled from blocks colored like stage 2's components.

04
Fig. 04 · Entry 03 · Research questions

One pillar is chaos, the other has rules

Instead of listing “high variation” and “low variation”, the figure lets readers see variation. Each new sample reshuffles both sides. Culture changes completely. Content changes too (more cards, the image on the other side), but the structure holds: the header stays on top, the footer at the bottom, everything snaps to the grid.

Replaces
Why it works

This is the argument the whole study rests on, so it gets the most interactive figure. “Show the rules” overlays the grid and labels the fixed slots, which turns “follows a set of rules” into something the reader can check.

It also sets up Q1 and Q2: if content behaves like the right panel, it can be mapped and automated.

Template summarization

Your method in four steps. Two item-detail pages have different lengths, so their sections land at different heights. Segmenting them into template sections and summarizing each into a same-size frame makes them comparable. Stacking the frames reveals the shared structure.

Replaces (and connects)
Why it works

Today the method is spread across several static images (the size comparison, the template example, the stacked view). This figure tells it as one process the reader steps through, using the original legend colors.

The page heights use the real Dell item-detail numbers from the study: 18,482 px and 19,432 px.
