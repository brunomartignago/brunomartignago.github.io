Sketch A3 · AI Orchestration · entry 01

Combined, it becomes exponential

Four data sources (Typology, Purchasing, Social, Surfing) can be switched on one by one. Each one sharpens the picture of the person, and the “ability to engage” meter grows faster with every source added. That is the page's claim, “every data source has great value, but combined, it becomes exponential”, made visible.

  • Replacesdata_structure.png
  • Real labelsPerson · Typology · Purchasing · Social · Surfing
  • Illustrativemeter values (labelled “illustrative” in the figure)
  • Plays once in view: the sources switch on one after another (~700ms each); the profile comes into focus and the meter grows, faster each time.
  • Reader drives: each source is a toggle button (aria-pressed); any combination.
  • Reduced motion: static with all four on. No JS: data_structure.png.
